# Canic 0.100 Changelog

## [0.100.1] - 2026-07-25 - Tree Configuration Hard Cut

### ⚠️ Breaking

- Replaces `[subnets.*]` and `[services.fleet]` with `[tree_specs.*]` and
  `[tree_groups.*]`. `canic app role attach` now requires
  `--tree-spec <tree-spec>`; removed config and CLI forms have no aliases.
- Replaces the logical environment Subnet Slot selector with a Tree Spec
  selector as a bounded implementation step. This is not final protected Tree
  identity and no earlier installation is decoded.

### ➕ Added

- Validates one root per Tree Spec, exact Spec references from Tree Groups,
  positive ordered initial/maximum counts and a 4,096-Tree Fleet capacity
  bound.
- Compiles Tree Specs and Tree Groups into generated bootstrap configuration
  and derives role, pool and lifecycle projections across heterogeneous Specs.

### 🔧 Changed

- Updates scaffolding, checked-in App and probe configuration, host
  projections, role mutation, build support and CI downstream fixtures to the
  new declaration language.
- Keeps the current root installer explicitly bounded to one initial Tree. A
  larger valid declaration fails during immutable build-input validation,
  before receipts or external effects, until Coordinator installation owns
  multi-Tree creation.

### 📚 Documentation

- Records the complete live topology authority inventory and the remaining
  ordered cuts for protected Tree binding, Coordinator/Tree Root separation,
  Tree Registry and Tree Directory ownership.

## [0.100.0] - 2026-07-25 - Tree Identity Contracts

### ⚠️ Breaking

- Begins the reinstall-only 0.100 implementation line. No 0.99 installation,
  stable state, topology identity or compatibility decoder is an input to a
  0.100 Fleet.

### ➕ Added

- Added distinct `TreeSpecId` and `TreeGroupId` types for App-declared Tree
  topology and independent scaling groups. Both reject empty, noncanonical or
  over-40-byte names at Serde and Candid boundaries.
- Added generated 32-byte `TreeId` for one concrete Fleet-scoped Canister
  Tree. Its text, Serde and Candid representations are exact 64-character
  lowercase hexadecimal.
- Re-exported the three Tree identity types through the public Canic facade.

### 📚 Documentation

- Opened the 0.100 implementation tracker against immutable `v0.99.34` and
  recorded the staged hard-cut boundary: these foundational contracts do not
  make the remaining 0.99 Subnet Slot or Fleet Root runtime releasable as
  0.100.

### 🧪 Testing

- Focused core tests cover declared-name bounds, invalid Serde input, Candid
  round trips and canonical concrete Tree identity encoding.
