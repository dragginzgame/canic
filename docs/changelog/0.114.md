# Canic 0.114 Changelog

## [0.114.0]

### 🩹 Fixed

- Restore plain Cargo's `target/` default so `cargo clean` removes all disposable
  build output, generated packages, Wasm caches and retained evidence. Make build
  subprocesses retain `target/cargo/` to separate generated source from compiler
  output; `make clean` and `make release-clean` explicitly clean the whole tree.
- Let each independent Blob consumer workspace use and clean its own `target/`,
  removing the inherited redirects into their parent's shared output directory.
- Direct Cargo CLI smoke lookup follows `target/debug/`; explicit output overrides
  remain supported. Preserve needed evidence elsewhere before cleanup and do not
  clean while builds are active. No automatic cleanup or cache migration runs.
