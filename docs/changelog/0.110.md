  canisters, including Root relay and host transport. Report actual bucket
  usage, physical/virtual extents, ledger allocation and unknown ownership

  sharing one ic-memory 0.13.2 runtime. Restore the reviewed allocation-report
  work now that the published dependencies align. Storage uses owned runtime

  with instruction/cycle savings still unmeasured.

  subsequent decisions, effects and replays read fresh state.

  their current release identity. A six-role comparison reduces extraction

  wall time from 112.89s to 85.03s with identical Wasm, gzip and Candid bytes.

  background workers before returning a build failure. Cargo remains serial;
  compiler settings, artifact validation and release identity stay unchanged.

  admission order, public ordering, retention and byte limits remain unchanged.
