# Canic 0.112 Changelog

## [0.112.0] - 2026-10-28

### 📝 Summary

- Isolate synthetic qualification fixtures from an enclosing release's source
  identity while retaining production source matching and mismatch regressions.

- Admit maximum application initialization bytes together with managed authority
  in the bounded Wire installation envelope; retain the wire-size, depth and
  application byte caps. Coordinator snapshot tests assert the exact transport
  fence rejection and unchanged registry after attempted activation.

- Make preparation and qualification select the same managed compiler-cache
  environment without manual exports. Pin sccache 0.19.0 with its upstream archive
  checksum, isolate its runtime by version, and reject mismatched explicit cache
  binaries. Preserve explicit output, wrapper and incremental selections; prepare
  the same managed environment before macOS native tool builds. Keep generated-input
  regression setup and cleanup in focused helpers so test-target Clippy passes.
  Isolate copied cache-wrapper fixtures from Make runtime overrides and reject
  missing cleanup directories instead of reporting a false pass. The contamination
  fixture gives output ownership exclusively to its build specification, including
  when invoked with Make-exported Cargo output. Resolve retained configuration
  aliases before deriving generated Root package identity, so recovery finds the
  same selected source without weakening output or package admission.

- Separate repository compiler output (`target/cargo`) from configuration-keyed
  Fleet source (`target/canic-packages`). Reject overlapping explicit outputs
  before generation; retain normal selected-source input admission. The installed
  snapshot regression observes the expected pre-dispatch transport refusal directly
  and verifies unchanged inventory after rejected allocation. Package proofs discover
  archives from Cargo metadata, including explicit output overrides; restored Root
  rejection checks the specific typed `CanisterCalledTrap` transport code. Validate
  nested generated-package aliases before writing; the offline Wasm crypto checker
  consumes the shared preparation step instead of fetching again.

- Centralize release/CI prerequisite preparation and qualification group membership.
  Fetch all three locked Cargo graphs explicitly; keep dependency fetching out of
  security checks and preserve local/CI failure barriers without result caching.
  Prepare the shared Rust tools for preflight consumer fixtures, the release Wasm
  target, and locked dependencies before `update-dev` audits.

- Isolate generated Fleet packages from application source fingerprints and share
  build-environment normalization with internal artifact production. Correct
  snapshot prepare/resume admission while retaining release-fence rejection.
- Share fresh release qualification, retain consumer boundary checks, prepare
  offline CI dependencies and the pinned metadata editor, and preserve failure
  diagnostics. Alternate staging uses the adapter roster, including private locks.

- Adopt Auth/protocol types 0.19.0 and Timers 0.31.11 in all three lockfiles.
  Match typed login states during restore. Adapt the durable session qualification
  backend to explicit read/admit/logout operations and protected credential
  admission; retain atomic records, replay accounting and revocation checks.

- Lock artifact and native schema production at the shared Cargo target boundary,
  including independent Blob consumers. Prepare generated infrastructure before
  capturing fixture source inputs. Register manually mounted fixture Wire methods
  in both native schemas and Wasm declarations without changing their guards.
  Build audit Root fixtures under their selected App's canonical package contract.
  Align installed assertions with deferred initialization recovery, Store-owned
  timestamps and the sealed Root's pre-dispatch funding rejection; retain exact
  artifact, replay and cycle-conservation checks. Select the test canister's
  delegated-token and attestation-verifier features consistently across its
  canonical, sharding and Root-capability profiles.
  Bind installed readiness observations to the recorded controller, use Store's
  role overview for snapshot bootstrap, and report rejected readiness queries
  immediately. Keep internal Root-authorized GC available through paused Fleet
  modes while ordinary updates remain fenced.

- Raise admission-request visitor allocation accounting to 1 MiB so maximum
  Root and target policies round-trip, retaining the 16 KiB frame, node and depth
  limits. Record the four read-only Root authority/registry endpoints in the
  replay inventory. Align startup conversion and timer-custody guards with the
  current adapters, and require a feature-gated native schema producer for
  canister rlibs. Use native Wire authority hash evidence, raw hex ICP fixtures
  and shape-specific argument budgets. Leaf codec tests exercise pure response
  construction without bypassing the endpoint's memory/startup admission.

This release coordinates the owned Candid-to-Wire transport cut, release-bound
schema/client delivery, shared runtime and Host ownership, and retained-code
simplification. Required external IC/provider protocols retain Candid; the
cut preserves externally specified signed bytes and uncertain-payment obligations.
Owned initialization and authority hash contracts deliberately change together.
Memory, Auth and other explicitly changed state contracts follow the clean-reinstall
boundary described below.

The main workspace and both independent Blob consumers require published
Platform 0.7.0 and Blob Storage/Contracts 0.51.0. The consumer locks select the
Memory/Storage 0.51.10, Timers 0.31.11 and Wire 0.7.18 closure. Platform's new optional
external-contract modules are available for follow-on mirror removal; this
dependency adoption does not itself replace those Canic DTOs or change codecs.
Platform retains the previously published management/history/ECDSA
and ICRC transfer/consent exports. Browser qualification uses Platform 0.1.1
with the unchanged SDK Core 6.1.1 identity.
Adopt Tooling/Host/Testkit 0.69.0, Query 0.75.0 and Auth 0.19.0 in the root
catalog, preserving feature selections. The root lock selects Backup 0.45.1
within the catalog's 0.45 requirement. Refresh the canonical Shared Tooling
0.26.23 snapshot from its committed exporter, including current Candid boundary,
error, subprocess and scanner guidance without uncommitted producer work. Regenerate the checked-in
allocation peer and its provenance when the selected graph changes its bytes.

### ⚠️ Breaking

- **Supplier refresh:** adopt Platform 0.7.0, Blob Storage/Contracts 0.51.0,
  Auth/protocol types 0.19.0, Tooling/Host/Testkit 0.69.0, Query 0.75.0 and
  Backup 0.45.0 with matching public type identities. Select Memory/Storage
  0.51.10 and Timers 0.31.11 across the applicable consumer graphs. Blob-owned
  records use its bounded Wire storage contract; preserve existing installation
  obligations. Refresh the canonical Shared Tooling snapshot to 0.26.23.

- **Owned Candid removal:** remove owned `CandidType` derives and manual
  implementations, including identifiers, configuration, observations and hash
  projections. Managed initializers and exact caller tuples now use bounded
  native Wire; external management installation retains its Candid envelope.
  Authority/receipt hashes and opaque directory cursors use native Wire payload
  encoding with their exact identity bindings. Retained Host evidence uses
  `registry_wire_hex` and `status_wire_hex`; fixture and replay records use
  canonical storage. Regenerate artifacts and cleanly reinstall without fallback
  readers. Use published Platform management/status/snapshot/account/error types
  where available. Capacity-import recovery decodes published Platform
  `ChangeDetails` instead of its local enum, retaining exact controller/origin/
  sender-version checks and refusing unrelated change kinds. ICRC-21 handlers return standard `Result`, removing the copied
  response enum while retaining the required external standard encoding.

- **CBOR storage:** replace Canic's Ciborium dependency with the IC stack's selected
  `serde_cbor` 0.11.2. The current storage boundary represents every nested unsigned
  128-bit value as exactly 16 big-endian bytes, preserving the full cycle range
  without changing numeric Wire DTOs. Decode exactly one value and reject invalid
  amount widths. External IC CBOR, canonical hash arrays and separately fixed-width
  storage retain their own formats. This is a reinstall-only storage hard cut with
  no numeric fallback or predecessor-state reader. Record the maintainer-approved
  unmaintained advisory exception against the exact package/version/checksum.
  Keep the standard feature selection: optional CBOR tag preservation changes
  IC envelope decoding through Cargo feature unification.
  Parse stored values once through a private borrowed tree to keep the managed
  Root within Wasm installation limits; preserve duplicate-field rejection and
  stream encoding directly. This trades temporary allocation for code size.
- **Blob funding surface:** remove `canic_blob_service::funding::confirm_credit`.
  The adapter exposes preparation, dispatch and bounded renewal through Blob's
  installed workflow access. Independent-credit reconciliation needs an actual
  authenticated evidence source and installed acceptance before Canic can expose
  it. Existing uncertain payment obligations, replay refusals and same-release
  restoration remain intact.
- **Owned protocols:** replace role-command, status and observability unions with
  typed native Wire methods across Root, Coordinator, Wasm Store and managed
  roles. Change callers, compiled profiles, retained schemas and generated
  bindings together; remove exhausted selectors and Candid projections
  ([#613 — Hard-cut frontend bindings and release artifacts to Wire](https://github.com/dragginzgame/canic/issues/613)).
- **Fleet transitions:** use native typed actions for planning, observation, execution
  and lost-response recovery. Remove the generic Candid-text transition runner,
  hidden step list, artifact-digest map and duplicate readiness projection. Retain
  reviewed desired input directly in the current journal shape. Managed native Wire
  argument encoding retains exact artifact hashes, authority bindings and its
  owning initializer budget; external drain contracts remain separate. Recovery fixtures exercise native actions, including Store publication
  and the terminal-status barrier before retirement.
- **Endpoint inspection:** `canic info endpoints` reads retained Wire schemas.
  JSON exposes method IDs, modes, type definitions and codec budgets; tables show
  native request/reply shapes. Default inspection uses exact retained installed
  release evidence; `--release-build` remains the explicit offline source.
- **Artifact admission:** regenerate canonical Coordinator and Store DIDs from
  their compiled declarations. Validate exact Candid/raw/Wire export names and
  modes for every finalized artifact, including embedded-Candid builds, before
  replacing the retained artifact set. Reject duplicate codec ownership.
- **Bounded calls:** admit complete operation IDs and receipt-backed release
  cursors under explicit traversal/allocation limits while preserving request
  byte ceilings. Store planning measures the complete Wire frame instead of
  allocating a serialization used only for its length.
- **Maintained guidance and fixtures:** update starter endpoints, call guidance,
  CLI schema inspection, metrics, funding and release censuses to their native
  Wire methods and budgets. Document external Candid separately from managed native Wire initialization. Match private installed-fixture helpers to the same feature
  conditions as their callers so ordinary native checks compile independently.
- **Obsolete tooling:** remove the Candid delegation-proof benchmark and its sole
  Criterion dependency. Native endpoint transport, canonical signed bytes and
  stored proof records retain their owning checks; no performance saving is claimed.
- **Frontend export:** require explicit `--node` and `--typescript` paths and
  produce strict ES2022 JavaScript/declarations from sealed schemas and retained
  supplier runtimes. Replace owned DID factories with generated native codecs.
- **Memory composition:** use an explicit provider with
  `canic::start!(memory = application_memory(), ...)`, extend framework requests,
  and select checked pools/admission. Remove retired declaration/admission macros,
  the no-argument runtime facade and unused reservation callback
  ([#527 — Qualify Memory composition and diagnostics](https://github.com/dragginzgame/canic/issues/527),
  [#559 — Adopt the reservation hard cut](https://github.com/dragginzgame/canic/issues/559)).
- **Memory diagnostics:** use checked numeric slot IDs, permanent bindings and

- **Storage APIs:** use IC Storage's governed collections and bounded cells with

- **Access predicates:** custom predicates implement synchronous

- **Application Auth:** remove delegated-token application issuance/retrieval,

  `auth.allowed_token_scopes`. Remove unused token rejection helpers and retire

  Checkpoint names, including `.calls`, fit 128 bytes; retain at most 128 checkpoint

  `compile_role_build_sources(config, role, wasm_store)` and its diagnostic TOML

### 🧭 Migration Notes

- Rebuild the complete Canic publication family and application artifacts,
  regenerate client bindings, and **cleanly reinstall across releases**. Do not
  decode predecessor state to continue it, add fallback codecs or run mixed
  protocol generations. Same-release interruption recovery remains required.
- Update direct memory declarations/providers, synchronous access predicates,
  changed diagnostic/Host error matches and exposed upstream Rust types. Consumers
  exchanging runtime handles must use a compatible canonical dependency identity
  within each deployed graph.
- Remove deleted auth scope/token configuration, lower oversized log-entry limits,
  and replace or omit zero top-up amounts. Preserve application creation quotas
  and explicit funding headroom rather than treating caller authentication as a
  spending budget.
- Regenerate metrics/report consumers for decimal cycle strings, coverage fields,
  overflow identities, wide counters and per-family history truncation.
- Store overview creation/publication/GC/retirement times are whole Unix seconds;
  stop dividing creation time by one billion. The exact `adopted_at_ns` receipt
  remains nanoseconds and same-operation retries retain it
  ([#538 — Normalize Store creation timestamps](https://github.com/dragginzgame/canic/issues/538)).
- Prepare pinned Node and TypeScript explicitly for frontend export. Import SDK
  Core capabilities through published `@tokostudios/ic-platform@0.1.0` exports;
  retain application-owned trust roots, budgets, authorization and retry policy.
- Rerun the host/IC/Rust setup and offline checks required by the selected catalogs;
  keep `.tools/rust/common/bin` on PATH and use the selected Testkit executable.
  This is contributor setup, distinct from library compatibility
  ([#461 — Adopt common setup and verification](https://github.com/dragginzgame/canic/issues/461)).
- **Live Backup limitation:** `canic backup create` remains unavailable pending its
  Fleet/checkpoint authority and consistency adapter. Restore recovery and the
  participant SDK do not establish complete live capture
  ([#394 — Implement live Fleet backup capture](https://github.com/dragginzgame/canic/issues/394)).
- **Auth limitation:** portable enrollment, receiver refresh and production endpoint
  integration remain unavailable. Keep the production clock-skew activation gate
  closed; native adapter qualification is not installed production or TEE evidence.
