# Canic 0.112 Changelog

## [0.112.0]

- Select library targets for configured canisters, Fleet Coordinator and Wasm
  Store builds, including declaration passes. A same-name binary cannot replace
  or prevent the selected library artifact. Keep named-library Cargo JSON
  selection, profiles, features and qualification-first publication unchanged.
- Bind the same internal Cargo library selector into complete-build input
  identity. Earlier identities rebuild conservatively; retained records and
  their format/namespace remain intact, without another reader or cleanup
  ([#542 — Bind Cargo library selection into reuse identity](https://github.com/dragginzgame/canic/issues/542)).

### Testing

- Cover library/binary collisions with an actual Cargo Wasm build and check
  library selection in configured and infrastructure commands.

### Fixed

- Normalize worker custody and executable-resolution fixture expectations within
  physical temporary paths, retaining foreign and symlinked scratch refusals
  ([#474 — Retain complete PocketIC evidence](https://github.com/dragginzgame/canic/issues/474)).
- Bind Cargo and identity probes to the compiler whose sysroot the embedded peer
  remaps. Select the compiler, remaps and fixture settings in one complete
  environment map so fresh checkouts reproduce the same peer bytes.
  Refresh the peer and source/tool/lock provenance through the existing
  owner; normal preflight still verifies current inputs before server startup
  ([#551 — Refresh embedded allocation peer](https://github.com/dragginzgame/canic/issues/551)).
