# Canic 0.113

## [0.113.0] - Unreleased

### ⚠️ Breaking

Adopt published Persistence Memory/Storage 0.55.1 with Blob/Contracts 0.56.0 in
the root and both private Blob consumer lockfiles. Blob's public Memory boundary
requires matching host types, so these are one coordinated adoption. Select
Metrics 0.17 and Timers 0.32 for shared arithmetic identities. The maintained
locks select Metrics 0.17.3, Platform/macros 0.7.6 and Wire/derive 0.7.21; unrelated
package identities, features and compiler selections are preserved. The root's
unchanged host Query dependency still selects Metrics 0.16 privately; it is not
another deployed metric engine or an interchangeable public arithmetic type.

The growth-refusal test backing delegates physical identity to its underlying
shared VectorMemory, preserving Memory's exclusive-custody boundary and fault
injection. Production allocation and collection ownership remain unchanged.
No compatibility bridge or second runtime is introduced.

Blob's published 0.56 cut preserves allocation, collection and Blob record bytes,
but its existing cross-release retirement/reinstall policy still applies: retain
or discharge real obligations before retirement. This contribution performs no
upgrade, reset, release, publication or deployment.

### 🧭 Integration Notes

This isolated dependency contribution starts from published main, not the active
uncommitted 0.113 batch. Preserve that owner's newer Auth/Backup/tooling choices,
Blob adapter relocation, heap Logging integration and provider-metrics work when
integrating. [PR #708 — Provider metrics storage](https://github.com/dragginzgame/canic/pull/708)
remains the provider policy owner. When its stable store is integrated, select
Metrics Stable from the same Persistence 0.55 family and follow Persistence's
explicit old-metrics-data retirement contract. This published base uses neither
Metrics Stable nor Logging Stable, so no unused stable-adapter dependency or
second logger is added here. Stable Logging integration remains separate.
